# 不可説 — 文明の継承

施設を買い、条件付きの技術を研究して、狩猟→農耕→工業→情報と進む放置・クリッカーゲームです。

## 起動

`play.html` はCSS・JavaScriptを内包した単一ファイル版です。`index.html` は同じフォルダの `style.css` と `game.js` が必要です。

```sh
npm run dev     # PythonのHTTPサーバー、ポート3000
npm test        # ゲームルール・保存移行のテスト
npm run balance # 3種類の訪問頻度を比較する参考シミュレーション
npm run export  # engine.js/app.js等からgame.js/play.htmlを再生成
```

依存パッケージ不要。Node.js 24・Python 3.12で確認しました。環境再起動後はサーバーを起動し直してください。管理ブラウザではHTTP経由で開きます。

## 遊び方

- 手動採集または施設購入から開始。施設12種類、技術69種類、継承スキル6種類、革新スキル5種類。
- 施設10/25/50/100個で、その施設を2倍にする研究が解放されます。解放後に文明力を払って研究します。
- 時代の基礎技術は特定の施設数、手動獲得技術は通算操作回数、相乗技術は2施設と継承スキルを条件に解放します。
- PCでは施設を左、技術・継承・革新を右のカラムに表示。スマートフォンではタブを切り替えます。技術の分類・習得済み表示を選択できます。
- 施設購入・研究・転生は手動。オフライン生産は通常速度で最大7日分。
- 文明力は1万未満で整数表示、価格は切り上げ。万・億・兆から無量大数（10^68）まで対応し、10^72以上は指数表示です。生産の端数は内部で保持します。

## 転生とインフレ

**継承**：工業以降・機械化研究済み・周回累計1000億以上で可能。獲得ポイントは `floor((1+log10(周回累計/10^11))^2)`。生産・価格割引・開始施設・手動獲得・農耕以降の生産・相乗効果の解放に投資できます。必要ポイントは基礎価格×4^現在レベル。継承回数・前提スキル・通算記録によって候補が解放されます。

**飛躍**：継承3回・スキル合計8レベルで永続解放。電力網を研究し、周回累計 `10^(18+3×飛躍回数)` で実行できます（条件の指数は最大240）。革新ポイントは `floor((初回1、以降3)+log10(周回累計/条件)^1.3)`。初回は条件達成で1ポイント、条件の10倍で2ポイント。基盤は1ポイントで購入します。2回目以降は条件達成で3ポイント、10倍で4ポイントです。通常の継承資産をリセットし、革新ポイント・革新スキル・通算記録を保持します。情報時代を解放し、工業以前の全51技術を習得済みで開始します。以後の継承・飛躍でも同様です。

革新ツリー：基盤（1ポイント、生産50倍・全継承スキル実効Lv＋2）→量産革命（2×3^Lv、生産5倍/レベル）・計算理論（3×4^Lv、指数+0.025/レベル）・情報経済（2×3^Lv、情報施設価格0.8倍/レベル）。量産Lv.2＋計算Lv.1→知能の融合（8、指数+0.05）。未使用ポイントは生産倍率にしません。

情報施設の基礎価格は1京・1000京・100垓、価格上昇は1.4倍/個。条件緩和・施設自動購入はありません。

## 保存・テスト操作

保存キーは `fukasetsu-civilization-v6`。今回の数値調整では保存形式を変えず、購入済みスキル・ポイント・施設をそのまま保持し、新しい飛躍条件と今後の報酬を適用します。過去の飛躍報酬の追加配布はありません。新セーブがなければv5→v4→v3→v2を検証して移行し、元データを残します。旧施設数ボーナスは該当する購入済み技術に変換し、削除済みスキルは当時の価格で返還。移行時点の時代・施設数・最高周回生産を履歴に記録します。旧版に存在しなかった手動操作履歴は0から記録します。

5秒ごと・離脱時にlocalStorageへ保存します。HTTPとローカルファイルでは保存領域が異なることがあります。

「テスト操作」に10倍速と初回飛躍直後へのスキップがあります。10倍速はリアルタイム生産のみを加速し、手動獲得は通常の額、再読み込みで通常速度へ戻ります。スキップ前の進行を保存し、再読み込み後も復元可能です。繰り返しスキップすると退避内容は直前の進行に更新されます。

設計の詳細は [docs/progression-design.md](docs/progression-design.md)、検証結果と調整上の制約は [docs/validation.md](docs/validation.md) に記載しています。現在は2段転生の試作です。3日で不可説不可説転を超える最終目標は未達・未調整で、各施設の毎秒生産を10^200で制限しています。

飛躍調整の3案比較は [docs/leap-balance-adjustment.md](docs/leap-balance-adjustment.md)。`node scripts/playtest/leap-candidates.mjs` で再比較できます。

GitHub Pagesの初回設定・公開手順は [docs/github-pages.md](docs/github-pages.md)。公開先は https://nonsuger634-web.github.io/incremantal/ （デプロイ成功後）。mainへの更新で自動配信されます。

開拓の記憶は開始文明力の増加を廃止し、狩猟の各施設5個/実効Lvを購入時と周回開始時に付与します。Lv1なら各5個、基盤の無料Lv2なら各10個。無料補正はスキル上限までで購入価格に加えず、通常継承・飛躍でも残ります。ツリーは未解放ノードも表示し、線でスキル前提を示します。履歴だけで解放する枝は線で結びません。
