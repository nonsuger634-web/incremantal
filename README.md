# 不可説 — 文明の継承

施設を買い、条件付きの技術を研究して、狩猟→農耕→工業→情報→宇宙と進む放置・クリッカーゲームです。

## 起動

`play.html` はCSS・JavaScriptを内包した単一ファイル版です。`index.html` は同じフォルダの `style.css` と `game.js` が必要です。

```sh
npm run dev     # PythonのHTTPサーバー、ポート3000
npm test        # ゲームルール・保存移行のテスト
npm run balance # 3種類の訪問頻度を比較する参考シミュレーション
npm run export  # engine.js/app.js等からgame.js/play.htmlを再生成
```

依存パッケージ不要。Node.js 24・Python 3.12で確認しました。環境再起動後はサーバーを起動し直してください。管理ブラウザではHTTP経由で開きます。

## 遊び方

- 手動採集または施設購入から開始。施設15種類、技術90種類、継承スキル6種類、革新スキル5種類、超越スキル4種類、時空スキル11種類。
- 施設10/25/50/100個で、その施設を2倍にする研究が解放されます。解放後に文明力を払って研究します。
- 時代の基礎技術は特定の施設数、手動獲得技術は通算操作回数、相乗技術は2施設と継承スキルを条件に解放します。
- PCでは施設を左、技術・継承・革新・超越・時間を右のカラムに表示。スマートフォンでは施設の下で管理タブを切り替えます。施設は常時表示します。技術の分類・習得済み表示を選択できます。
- 施設購入・研究・転生は手動。オフライン生産は通常速度で最大7日分。
- 文明力は1万未満で整数表示、価格は切り上げ。万・億・兆から無量大数（10^68）まで対応します。1無量大数突破のクリア後は八十華厳系へ切り替え、倶胝・頻波羅・矜羯羅・阿伽羅などを使います。係数は日本式の万・億など、大きな値は単位を重ねて表示し、指数表記は使いません。文明力の単位は「点」です。生産の端数は内部で保持します。

## 転生とインフレ

**継承**：工業以降・機械化研究済み・周回累計1000億以上で可能。獲得ポイントは `floor(max(0,R(E)-10)^2.7)`。生産・価格割引・開始施設・手動獲得・農耕以降の生産・相乗効果の解放に投資できます。必要ポイントは基礎価格×4^現在レベル。継承回数・前提スキル・通算記録によって候補が解放されます。

**飛躍**：継承3回・スキル合計8レベルで永続解放。電力網を研究し、周回累計 `10^(18+3×飛躍回数)` で実行できます（条件の指数は最大240）。革新ポイントは `floor((max(0,R(E)-16)/2)^1.3)`。初回条件で1ポイントを得て基盤を購入でき、1垓で2ポイント、10垓で3ポイント。初回・回数による基礎報酬はありません。通常の継承資産をリセットし、革新ポイント・革新スキル・通算記録を保持します。情報時代を解放し、工業以前の全51技術を習得済みで開始します。以後の継承・飛躍でも同様です。

革新ツリー：基盤（1ポイント、生産50倍・全継承スキル実効Lv＋2）→量産革命（2×3^Lv、生産5倍/レベル）・計算理論（3×4^Lv、指数+0.025/レベル）・情報経済（2×3^Lv、情報施設価格0.8倍/レベル）。量産Lv.2＋計算Lv.1→知能の融合（8、指数+0.05）。未使用ポイントは生産倍率にしません。

情報施設の基礎価格は1京・1000京・100垓、価格上昇は1.4倍/個。基礎生産は毎秒10兆・1京・1000京で、上位施設へ進むごとに1000倍になります。継承スキルは購入レベルと革新補正を `Lv. 0 (+2)` の形で表示します（補正は上限まで）。条件緩和・施設自動購入はありません。

**超越**：初回は飛躍3回・情報時代・知能の連鎖研究・周回累計100穣（10^30）で実行できます。超越回数ごとに条件が10桁上がり、報酬は `floor(max(0,R(E)-26.2)/3.8)`。初回条件で1ポイント、累計が3.8桁増えるごとに1ポイント増加。記憶の定着の倍率を適用します。継承・飛躍の資産をリセットし、超越スキル・ポイント・通算記録を保持します。再開時には革新の基盤を付与し、情報までの全69技術習得済みになります。宇宙の基盤取得後は情報時代・工業までの各施設100個から開始します（未取得なら狩猟各10施設）。

宇宙の基盤（1ポイント）で生産指数が1.2になり、宇宙時代へ進めます。軌道都市・恒星炉・銀河演算網の生産を指数で伸ばし、1無量大数を目指します。次元の拡張で指数+0.15/レベル、時空の圧縮で宇宙施設価格×0.65/レベル、両枝の前提を満たすと無限への接続で指数+0.15。下位の継承・飛躍でも超越資産を保持します。詳細は [docs/transcend-design.md](docs/transcend-design.md)、比較プレイは [docs/transcend-playtest.md](docs/transcend-playtest.md)。

## 保存・テスト操作

**タイムマシン開発**：1無量大数突破で解放。報酬は全文明の累計生産から算出した総額と受取済み額の差分です。使用済みポイントも受取済みに含めます。技術保存は通常技術だけを付与し、Lv.2は全施設1000個の到達記録を条件に購入し、全施設1000個で再開します。時空研究は歴史の共鳴Lv.5・9・13で研究済みのものを固定化。「文明の永久記録」は下位スキル・ポイント・回数を保持し、各層の累計生産・受取済み額も保持し、未受取分を補充します。生産の上限は設けず、全強化時の計算結果が目標の0.0033倍/秒になるよう最終スキル倍率を調整。仕様は [docs/time-travel.md](docs/time-travel.md)。

保存キーは `fukasetsu-civilization-v9`。v8の施設・技術・購入スキル・ポイント・クリア記録・履歴を保持し、時空ツリーと最終達成記録を追加します。v7以前も移行できます。旧キーは残し、新セーブがなければv8→v7→v6→v5→v4→v3→v2を検証して移行します。古い数量倍率は取得済み施設技術へ変換し、削除済みスキルは旧価格で返還します。

5秒ごと・離脱時にlocalStorageへ保存します。HTTPとローカルファイルでは保存領域が異なることがあります。

「テスト操作」に通常・10倍・100倍の速度切り替えと1〜3回目の飛躍直後・初回超越直後・クリア直後・初回タイムマシン開発後へのスキップがあります。倍速はリアルタイム生産のみを加速し、手動獲得は通常の額、再読み込みで通常速度へ戻ります。スキップ先は革新未購入で、未使用ポイントは順に1・3・6です。施設の購入ボタンは価格上昇込みの合計価格と買える施設数を表示します。スキップ前の進行を保存し、再読み込み後も復元可能です。繰り返しスキップすると退避内容は直前の進行に更新されます。

設計の詳細は [docs/progression-design.md](docs/progression-design.md)、検証結果と調整上の制約は [docs/validation.md](docs/validation.md) に記載しています。現在はクリア後を含む4段転生です。巨大な文明力は対数で保存し、生産上限10^200を撤廃して、実際の生産で1不可説不可説転に到達できます。現在の連続操作・手動採集なしの検証は末尾の資料を参照してください。

飛躍調整の3案比較は [docs/leap-balance-adjustment.md](docs/leap-balance-adjustment.md)。`node scripts/playtest/leap-candidates.mjs` で再比較できます。

GitHub Pagesの初回設定・公開手順は [docs/github-pages.md](docs/github-pages.md)。公開先は https://nonsuger634-web.github.io/incremantal/ （デプロイ成功後）。mainへの更新で自動配信されます。

全4リセットは条件達成後に、次のポイント増加時の報酬・必要周回累計・あと必要な文明力を表示します。記憶の定着による超越報酬倍率も表示に反映します。

現行調整の検証は [docs/permanent-record-and-endgame.md](docs/permanent-record-and-endgame.md)。クリア時間を日・時間・分・秒で保存し、「クリアログ」から書き出せます。各リセットの確認は画面全体のvignette付きダイアログです。

UIは未発見のリセット段階を隠し、最終目標名はその単位が生産量や文明力へ出現するまで「？？？？？？？」と表示します。PCでは施設を左、全管理タブを右に統一。スキル倍率はカードと文明力の下に表示し、リセット確認には消えるものと報酬だけを載せます。通常説明14px、購入操作13〜14pxを基準とし、色と文字で購入可否を示します。


## 画面表示と進行ガイド

次の目標は農耕・工業・継承・飛躍・情報・超越・宇宙・時間跳躍の解放条件に合わせて切り替わります。新システムの説明は画面内に表示し、確認するまで生産とプレイ時間を停止します。確認済みの説明はセーブに保持します。

研究は条件を満たしたものを価格順に表示します。上部の研究ボタンを繰り返し押すと、表示中で購入可能な研究を安い順に1件ずつ習得します。分類フィルターを反映します。

数値欄は折り返しを見込んだ高さを確保し、手動ボタンと累計を別の領域に配置しています。タブ内のスクロールを廃止し、ページ全体でスクロールします。操作通知はメイン画面に表示せず、保存エラーは別途表示します。クリアログ・遊び方・テスト操作は開閉にかかわらず縦に並びます。

`npm run export` は単独で開ける `page.html` も生成します。GitHub Pagesにも同じファイルを配信します。

時間跳躍の報酬は全文明の累計生産から計算し、未受取の差分だけを獲得します。同じ累計から繰り返しポイントは得られません。実行に必要な周回生産条件は従来どおりです。4リセットの画面統一と到達時間の比較は [docs/reset-ui-and-lifetime-rewards.md](docs/reset-ui-and-lifetime-rewards.md) を参照してください。

最新の累計報酬・旧セーブ移行・連打なし検証は [docs/layer-rewards-and-no-click-playtest.md](docs/layer-rewards-and-no-click-playtest.md)。生涯の合計リセット回数と各層の回数を表示し、ポイントはアラビア数字・3桁カンマ区切りで「残り N pt」と表示します。

タブ選択ボタンの右寄せ・表現の統一と、初回時間跳躍後の超越16ptを約2分へ調整した検証は [docs/right-actions-and-first-time-balance.md](docs/right-actions-and-first-time-balance.md)。
