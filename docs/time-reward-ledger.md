# 時間跳躍の差額報酬と数値調整

全文明の累計生産から算出した報酬総額 − 受取済み総額だけを獲得する。受取済みには未使用ポイントとスキル購入に使ったポイントの両方を含める。周回生産の実行条件を満たしても、同じ全文明累計から再度獲得できない。

`timeAwards` は全リセット・保存復元で保持する。旧セーブに項目がない場合は、未使用ポイントと購入済みスキルの費用合計を受取済み額として移行する。既存資産は保持する。

時間報酬のoffset=60・scale=8を維持し、powerを1.3から1.7へ変更。初回は1ptのまま。最終目標時の総額2,022ptに対し、全時間スキル費用は1,631pt。逆算した次報酬の目標にも受取済み額を含める。

全強化・全施設各1000・全研究時の秒給は、数値ライブラリの最終単位の係数を正確に0.0033に設定。目標1単位の生産には約303.030303秒。300秒の旧設定は更新した。

## ペース比較

初回時間跳躍後から開始し、毎日8時間放置・まとめ買いで検証。ゲーム全体の所要時間ではなく、定めた購入方針の比較。操作方法によって時間は変わる。

継承のポイントは所持額・報酬・次報酬・スキル費用・確認画面でアラビア数字と桁区切りを使用。飛躍解放は継承3回と購入スキル合計8レベルの両条件。解放後の飛躍条件にも解放済みと表示する。

単体テストで使用後の二重受取、累計増加時の差額、旧セーブ移行、下位リセットでの台帳保持、次報酬逆算、飛躍の解放境界、最終秒給を検証。スマホ・PCのリセット画面と320〜1280pxのレイアウトをブラウザで確認。
