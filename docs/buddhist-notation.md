# 無量大数以降の華厳経系表記

クリア前は日本式の万・億・兆から無量大数を使う。所持1無量大数を超えてクリアした時点から、価格・生産・ポイントも含め八十華厳系の数表記へ切り替える。クリア後にリセットして小さな値に戻ってもこの表記を保持する。日本式の那由他と八十華厳の那由他は異なる値なので、表記モードを画面に表示する。

華厳経系は倶胝10^7から各段階で指数を2倍にする。頻波羅10^56、矜羯羅10^112、阿伽羅10^224、最勝10^448。不可説不可説転の指数は `7×2^122`、つまり `37218383881977644441306597687849648128`。

係数は読みやすい日本式の万・億などで表示し、係数が10^72以上になる場合だけ指数表示にする。例えば1秭 矜羯羅は `10^24×10^112=10^136`。名前だけを既存の10^72に割り当てることはしない。係数を切り捨て、単位の切替境界で名前が先走らないようにする。

`formatNumber` はNumber型と巨大数の対数表現に対応する。有限の値は従来のNumber計算を維持し、範囲を超える値は `{log10: 指数}` で保存する。加算・減算・乗算・比較・オフライン生産・施設購入・リセットは両方を扱う。施設の10^200生産上限は撤廃し、スキルツリーを伸ばすことで実際に不可説不可説転まで生産できる。

洛叉と、倶胝から不可説不可説転までの指数倍増系列123段、合計124単位を定義する。名称は八十華厳経の阿僧祇品にある系列を使い、説・転は日本語の字体で表示する。`formatPowerOfTen` はBigIntの指数を受け取り、単位の正確な指数を扱う。中間の巨大な係数は `10^(1.23×10^36) 単位` のように短縮する。

巨大数の計算は常用対数を浮動小数点で保持する近似であり、最終目標級の数値ではごく小さい加算・減算は表示や値に反映されない。施設・研究の価格と同じ規模の値を扱うときは差額を計算し、桁が大きく離れた価格を払うときは巨大な文明力に見える変化はない。整数全桁を正確に保持する演算ではないが、桁の成長・報酬条件・保存は無限大にならず進められる。

独自の「無量大数²」表記は採用しない。テストで日本式の既存境界、華厳の112/224乗境界、Number最大値、不可説不可説転の指数を検証する。
