# 無量大数以降の華厳経系表記

クリア前は日本式の万・億・兆から無量大数を使う。所持1無量大数を超えてクリアした時点から、価格・生産・ポイントも含め八十華厳系の数表記へ切り替える。クリア後にリセットして小さな値に戻ってもこの表記を保持する。日本式の那由他と八十華厳の那由他は異なる値なので、表記モードを画面に表示する。

華厳経系は倶胝10^7から各段階で指数を2倍にする。頻波羅10^56、矜羯羅10^112、阿伽羅10^224、最勝10^448。不可説不可説転の指数は `7×2^122`、つまり `37218383881977644441306597687849648128`。

| 10^7 | 1 倶胝 |

| 10^308 | 1×10^84 阿伽羅 |

係数は読みやすい日本式の万・億などで表示し、係数が10^72以上になる場合だけ指数表示にする。例えば1秭 矜羯羅は `10^24×10^112=10^136`。名前だけを既存の10^72に割り当てることはしない。係数を切り捨て、単位の切替境界で名前が先走らないようにする。

`formatNumber` は現在のNumber型の範囲を扱う。`formatPowerOfTen` はBigIntの指数情報を受け取り、最勝と最終目標の不可説不可説転も正確に表示できる。現行のスコア演算はNumber型・施設生産上限10^200のままであり、この表記追加だけで不可説不可説転までスコアを生産できるわけではない。中間の巨大な単位を全て列挙したものではなく、現在必要な範囲と目標の指数を定義している。

独自の「無量大数²」表記は採用しない。テストで日本式の既存境界、華厳の112/224乗境界、Number最大値、不可説不可説転の指数を検証する。
