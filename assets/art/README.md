# 文明の地平の生成画像

image_genで、このゲームの暗い青灰色・ミント・淡い青・金の配色に合わせて生成した画像です。各セルをCSSで切り出して表示します。元画像のPNGからピクセルを変えないlossless WebPへ変換し、比較誤差0を確認しました。

- facilities.webp: 5列×3行。FACILITIESの順で15種類。
- technologies.webp: 5列×5行。0–9は時代の基礎技術、10–14は手動研究、15–17は時空研究、18–21は施設研究の強化段階、22–24は予備。
- skills.webp: 6列×5行。継承6・革新5・超越4・時間11の順で26種類、残り4セルは予備。

施設研究は施設のアイコンに強化段階の印、連携研究は対象2施設のアイコンを重ねます。artwork.jsが90技術をそれぞれ異なる構成へ対応付けます。カタログ順やセーブ形式は変更しません。

施設・技術のアイコンは装飾としてaria-hiddenを付け、施設名・技術名・説明を残します。背景はカード内に不透明度0.16で重ね、ポインター操作を妨げません。習得状態・購入可能状態・選択状態の既存色は維持します。

index.htmlはこのフォルダの画像を読み込みます。npm run exportはWebPをdata URLへ変換し、page.html/play.htmlに内包します。これらの単一HTMLは画像用のネットワーク要求を必要としません。
